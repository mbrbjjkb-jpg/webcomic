GitHub に接続

データ置き場（リポジトリ webcomic）とつなぐため、 専用のアクセストークンを1回だけ入力します。トークンはこの端末のブラウザ内にだけ保存され、 コードやリポジトリには含まれません。

トークンの作り方

  1. GitHub にログイン → 右上のアイコン → Settings
  2. 左下の Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access で Only select repositories を選び、webcomic だけを指定
  4. Permissions → Repository permissions → Contents を Read and write に設定
  5. 発行されたトークンを、上の欄に貼り付けて「接続」
未読はありません 🎉
新しい更新があると、ここに自動で載ります。

作品の追加

追加した作品は次回の更新チェック（1日4回）で取り込まれます。 Web漫画アンテナのブックマークに入れた作品は、ブックマーク経由で自動的に取り込まれるので追加は不要です。
